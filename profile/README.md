# 🚀 iBizLab | 开源实验室


> **模型驱动 · 开源协同 · 技术赋能** | 构建下一代企业级应用的开源基石

欢迎来到 **iBizLab 开源实验室**！我们专注于为企业级应用开发提供**模型驱动、全栈打通、安全可控**的开源解决方案。我们坚信“**模型即系统，结构即代码，运行即协作**”，致力于通过创新的开源技术，赋能开发者与企业。

## 🌟 我们的核心

我们构建了一个统一的技术生态，覆盖前端、后端、建模、开发到部署的全链路：

*   **模型驱动开发 (MDD)**：通过 `iBizModeling` 实现 DSL 驱动、数据/界面/流程一体化建模，让开发更高效、结构更清晰。
*   **前后端一体化技术栈**：基于 模型被 iBizAppHub 映射为页面、表单与视图组件，快速产出可交付 UI，iBizServiceHub 解析并部署为运行单元（微服务、定时任务、路由等）。
*   **AI 赋能**：将 AI 技术融入建模与流程辅助，提升开发效率与智能化水平。
*   **安全可控**：支持 Docker 本地化部署，数据安全自主掌控，满足企业级需求。
*   **插件化架构**：所有平台均支持强大的插件机制，便于二次开发与生态扩展。

## 🛠️ 核心项目

我们正在积极开发和维护一系列高质量的开源项目：

| 项目 | 描述 |
| :--- | :--- |
| **[iBizModeling](https://modeling.ibizlab.cn)** | 一体化建模驱动开发平台，可打造专属低代码平台。 | 
| **[iBizAppHub](https://github.com/ibizlab-cloud/iBiz-app-hub)** | 基于 Vue3+Vite 的前端技术框架，支持微前端与海量组件。 | 
| **[iBizServiceHub](https://github.com/ibizlab-cloud/ibiz-service-hub)** | 负责模型的分发、解释、启动、路由与治理，实现“模型 → 微服务”的生产化交付链。| 
| **[iBizPLM](https://github.com/ibizlab/plm)** | 全流程协同的产品生命周期管理系统，对标一线商用软件。 | 
| **[iBizCRM](https://github.com/ibizlab/crm)** | 借鉴 Zoho 理念的强大客户关系管理系统，支持本地部署。 | 
| **[iBizEHR](https://github.com/ibizlab/iBizEHR)** | （开发中）对标一线的人事管理软件，融合人事、工资、考勤等，招聘、考勤模块已上线。 | 
| **[iBizOdoo](https://github.com/ibizlab/iBizOdoo)** | （开发中）Odoo 的 iBiz 技术栈实现，打造最佳商业套件基座。预览版已上线。 |

## 🤝 为什么选择 iBizLab？

*   **全栈打通**：从前端框架到后端建模，再到具体业务应用，提供统一的技术栈与体验。
*   **免费开放**：核心功能（如 AI 智能建模）已全免费开放，降低技术门槛。
*   **企业级就绪**：设计之初即考虑企业需求，支持本地化、离线运行，安全可控。
*   **活跃生态**：持续迭代，项目矩阵不断丰富，社区共同成长。
